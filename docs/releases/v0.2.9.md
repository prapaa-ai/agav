### Features

- Find loaded commands by name or description with `/help --search <query>`. Check context-window occupancy as JSON with `/context --json`, and see whether automatic post-update notes are enabled with `/changelog status`. (#764, #839, #969)
- Search saved session names and titles as well as messages with `/search`. Limit `/history list` with `--limit` or filter it with `--provider` and `--model`. An ambiguous `/resume` prefix now lists matching IDs instead of loading a session. (#729, #755, #762, #838)
- Search saved memories by name, description, or content with `/memory search`, read a complete entry with `/memory show`, filter `/memory list` by type, and rename an entry without changing its content or type. (#740, #763, #812, #855)
- Copy a single fenced code block with `/copy code [N] [--response M]`, including from older assistant responses. Use `/export --full` for complete retained tool text in Markdown, or `--branch-only` to export only messages added to the active branch. (#756, #786, #859, #929)
- Revert a specific file change with `/undo <n>` using its number from `/undo list`. Update a scheduled task's cron expression or prompt with `/schedule update` without replacing the task, and bulk-delete finished jobs and inactive schedules from the jobs manager after confirmation. (#847, #854, #870)
- Navigate more terminal views with the mouse, including the model picker, session picker, resource managers, request queue, and subagent views. The model picker can copy the highlighted ID with Ctrl+Y without switching models. Approval prompts have clickable controls, and shell commands can be expanded for inspection before deciding. (#793, #860, #864, #866, #867)
- Show the saved session name in the footer and the full session ID and available title in `/status`. Keep errors and warnings visible in the footer, with `/notices` available for details. Identify the MCP server on completed tool results and accept comma-formatted token counts in the context-window prompt. (#824, #837, #869, #966, #968)
- Give file and text searches more control: `grep_search` supports literal and case-insensitive matching, basename exclusions, surrounding context, and a configurable result cap. `find_files` adds relative paths and a configurable cap; `list_directory` can filter by entry type and include hidden entries; `overview` can map structure without reading source and can opt into hidden source paths. (#727, #728, #757, #760, #765, #766, #784, #788, #789, #840, #848)
- Read files with an explicit text encoding, read notebook cells by range and type (including raw cells), and omit cached notebook outputs when only source is needed. Use `edit_file` to replace a numbered exact match when the text occurs more than once. (#754, #761, #787, #842, #846, #951)
- Add issue and pull-request comments and explicit repository targeting to the GitHub tool. `fetch_url` accepts status-only `HEAD` requests, `web_search` accepts a bounded result count, and `run_tests` accepts a timeout override up to 10 minutes. (#785, #790, #804, #841, #845)

### Fixes

- Run supported inspection commands and targeted job stops during an active turn without switching views or weakening approval requirements. Defer commands that need to change the session or open another view, and show why they were queued. (#783)
- Reconcile detached sessions with dead owners without misclassifying completed sessions when process IDs are reused. On exit, distinguish active background jobs from ones whose status could not be verified. (#825, #931)
- Accept the first deliberate click on an approval without letting a double-click carry over to the next prompt. Keep the selected request when another queue entry is removed, and let Shift+Tab move backward through resource-manager forms. (#793, #932, #945, #947)
- Stack wide Markdown tables in narrow terminals, keep no-color icons aligned, and list built-in commands in their own help categories. (#675, #952, #954)
- Preserve literal dollar patterns in `edit_file` replacements and read notebooks whose cell source or cached output is stored as a string. Report test timeouts even when partial output looks successful. (#841, #849, #953)
- Default new Anthropic configurations to `claude-sonnet-5-5`, retain Ollama usage metadata from the final stream chunk, and preserve trailing equals signs in inline CLI values such as Ollama API keys. (#862, #944, #948)
- Reject `/loop` intervals above the timer limit, cancel pending callbacks when `/watch` stops or is replaced, and distinguish skills that have never run from skills with unsuccessful runs. (#946, #949, #972)
