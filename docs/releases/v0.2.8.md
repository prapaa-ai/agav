### Features

- Detach running sessions with `/detach` or Ctrl+D and reconnect through `agav --resume`, including progress and pending approvals. Requires `backgroundJobsEnabled: true` before starting the task; work continues in a local worker, not a cloud service. Tool details now use Ctrl+K Ctrl+E. (#591, #627)
- Redesign the session picker with name search, project/status filters, creation/activity sorting, and pending-approval indicators. Start a new session directly with N or Ctrl+N. (#626, #651)
- Add repeatable `-c key=value` / `--config key=value` session overrides, including nested settings, without changing saved configuration. Overrides propagate to workers and resume; dedicated flags and organization policy retain precedence. (#557, #628)
- Add `--provider-idle-timeout <ms>` and `providerIdleTimeout` to stop stalled provider responses without switching models. Preserve partial output and keep the session usable; tool execution, approvals, and retry backoff do not consume the idle timeout. (#576, #620)
- Show slash-command argument hints and immediately run commands marked for auto-submit when selected from the dropdown. (#621)
- Render a supported subset of LaTeX math as terminal-friendly Unicode, including Greek letters, operators, fractions, roots, and scripts; unsupported formulas remain literal. (#693)
- Honor `FORCE_COLOR` for colored output without a TTY, while preserving `NO_COLOR` precedence. (#706)

- Strip unsafe control characters from terminal-link URLs and correctly remove link wrappers when their visible text contains escape sequences. (#678, #679)

### Security and sandboxing

- Harden `fetch_url` against private/internal/metadata destinations and DNS rebinding by validating resolved addresses and pinning connections. Revalidate redirects and strip authorization, cookie, and proxy-authorization headers on cross-origin redirects. Local and private-network URLs are now refused. (#658)
- Require explicit per-call approval for mutating HTTP requests, even with auto-accept or tool allowlists; deny-writes blocks these requests, and headless calls without a confirmation handler fail closed. (#658)
- Run `run_tests` through the OS sandbox and credential filtering used for shell commands, without silently retrying unsandboxed when sandbox execution fails. (#630)
- Protect Git hooks/configuration, Agav/editor configuration, and shell startup paths on macOS and Linux. Linux commands run in private workspace snapshots and publish validated changes only after successful, uncancelled execution; failed commands do not publish workspace changes. Snapshot size and file-type limits can reject large workspaces or unsupported filesystem changes. (#633)
- Add explicit sandbox networking controls through `--sandbox-network` / `--sandbox-no-network`. Networking remains allowed by default. Deny mode blocks direct off-host networking on macOS and isolates Linux command networking; macOS host-local connections and reachable local relays remain trusted channels. Docker remains network-disabled. (#631, #649)
- Enable the native restricted-token sandbox and required-sandbox mode by default on Windows. Restrict writes and manage child-process lifetime; missing helper support blocks commands rather than falling back unsandboxed. Remove recorded workspace permission entries with `agav --revoke-windows-sandbox`. Reads and networking are not confined, so network-deny mode refuses execution. Protected paths that do not yet exist and locations writable by Everyone remain limitations. (#653, #654)
