### Features

- Bundled skills now ship **disabled by default**. All 21 are compiled into the binary but opt-in, so none are offered to the model or exposed as a slash command until you enable them with `/skills enable <name>`. Global and project skills remain enabled by default. (#614)
- Turn off the automatic post-update changelog with `/changelog off` and bring it back with `/changelog on`. The preference persists across updates; `/changelog` still shows release notes on demand. (#602)
- Sign in to a consumer Agav account with `/login` (or `agav login`). A bare `/login` opens an account wizard offering browser device-authorization sign-in or a masked API-key paste; the CLI collects the key through a masked prompt or stdin for scripts. Enterprise enrollment still runs when a login-flow flag is passed. Sign out of the account with `/logout --account`. (#597)
- Export the retained conversation as structured JSON with `/export json`, alongside the existing Markdown export. Add `sanitize` (in either order; `--sanitize` is an alias) for best-effort credential and home-path redaction — review the file before sharing. Exports never overwrite existing files and never change the active conversation. (#577)

### Fixes

- Restore encrypted-file credential storage and remove the OS credential-store integration. Agav no longer accesses the macOS Keychain, Linux Secret Service, or Windows Credential Manager, and performs no startup credential migration or OS-store authentication dialog. Replace any stored `keychain:` reference with the actual key or an environment variable; previously stored consumer-account references require signing in again. (#610)
- Make the session permission mode changeable and persisted, so a mode selected mid-session is retained and restored on resume. (#588, #611)
- Preserve subagent worker output through integration, protect merge destinations and retained worktrees, and align the merge preview with what execution actually does. (#578)
- Keep the TUI selection highlight from wrapping onto full-width rows. (#596)
