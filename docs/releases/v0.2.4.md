### Features

- The session picker now lists all saved sessions instead of only the latest 20, with mouse scrolling/click selection and a viewport that adapts to terminal resizing. (#388)
- Native agents can use an explicit allowlist of Agav's built-in tools. Select tools in the creation wizard or agent configuration; selections are preserved in saved templates. (#324)
- Pause and resume an active response with Ctrl+B or Alt+P, or submit a new prompt while paused to interrupt and redirect the turn. (#327)
- New sessions remember the most recently used provider and model when no explicit command-line or resumed-session selection overrides them. (#321)
- Linux clipboard image paste supports X11 (`xclip`) and Wayland (`wl-paste`), with bounded capture and image downscaling. (#313)

### Fixes

- Bound large tool outputs to reduce context/token usage. Shell and HTTP output can be saved to temporary logs with retrieval instructions; text file reads provide bounded excerpts and continuation ranges. (#391)
- Restore interrupt handling and propagate cancellation through tool execution, MCP request waits and provider retry backoff; clean up shell process groups on supported Unix paths. (#400)
- Ctrl+Q can exit after tool calls when idle, instead of being blocked by prior tool messages. (#323)
- Restore skill progress details and live token accounting without counting the final usage total twice. (#401)
- Render readable terminal hyperlinks instead of garbled escape-sequence fragments. (#403)
- Honor `overview` depth limits and report when its file cap makes the map incomplete. (#393)
- Treat successful structured test results as verification evidence, avoiding redundant verification rounds; edits invalidate prior evidence and failed checks take precedence. (#394)
- Resolve the requested branch/tag when installing agents from repository URLs, including branch names containing slashes. (#312)
- Restore sandboxed tooling's cache/config writes on macOS and Linux, and harden Docker isolation and UID handling for rootless/user-namespace-remapped daemons. (#343, #340)
- Reset repeated-paste tracking when the prompt changes so a later identical paste does not unexpectedly replace an earlier attachment. (#342)

### Other changes

- Cache the conversation prefix for Anthropic and Vertex-hosted Claude requests, and deduplicate verification instructions in the system prompt. (#358, #392)
- Replace the startup wordmark with a compact shell logo that also fits narrow terminals. (#395, #402)
- Refresh CLI/docs dependencies, expand offline SDK transport coverage, and update configuration, tools, agents, skills and session reference documentation. (#404, #390, #360)
- Isolate the release mirror's SDK installation from the application's dependency graph. (#406)
