### Features

- Enroll in an organization with `agav login` and sign out with `agav logout`, now also available in-session as `/login` and `/logout`. The CLI auto-selects the login flow and supports Authorization Code + PKCE (`--auth-code`), device flow (`--device`), OIDC token exchange (`--oidc`), and SAML brokered by the control plane (`--saml`). Restart Agav after login or logout to apply the enforced organization policy. (#570, #552, #558)
- Enterprise control plane: org-managed configuration tier enforced as the highest-precedence config, SSO login across all three auth flows, a SAML broker flow with audit→SIEM events and a login round-trip runbook, and injection of the enrollment gateway token into live model requests so a gateway-only enrolled developer needs no personal API key. The control plane is never on the inference path. (#552, #558, #556)
- See session, model, permission mode, working directory, and token usage at a glance with `/status`. (#537)
- Expose only the tools you need from large MCP catalogs with an optional per-server `tools` allowlist. Unlisted tools are left out of the schema sent to the model; unknown names are reported and ignored. (#561)
- Dictate prompts offline with `/voice`: an embedded, English-only native helper transcribes locally with no FFmpeg, whisper-cli, Python, or PATH changes. The composer stays editable during capture, and the English model is downloaded once on first use. (#534)
- Run long-lived shell commands and cron-style schedules that outlive a single turn with opt-in background jobs (`backgroundJobsEnabled`). The agent manages them with `run_background_job`; inspect and control them with `/job`. Schedules can run without the TUI via `agav job tick`/`agav job daemon`. Jobs run outside the shell sandbox. (#526)
- Customize the footer (status bar) with `/customize`: show, hide, and reorder segments. The layout persists in the `statusBar` config field and is reconciled against the current segment catalog on each start. (#543)
- Delegate a subagent task to a different model by passing an optional `model` parameter, subject to explicit per-call approval and the parent session's organization policy. (#545)
- Add a `minimal` reasoning-effort level alongside `low`, `medium`, `high`, and `max`, settable via `--effort`, `/effort`, and the `effort` config field (including per-agent overrides). (#547)
- Load user-level instructions from `~/.agav/AGAV.md` alongside project instructions. When both exist, user-level instructions are applied first, then the project's. (#536)
- Show the changelog automatically once on the first launch after an update; `/changelog` still shows it on demand. (#542)
- Delete a saved session from the CLI with `agav sessions delete <id>` (alias `rm`), accepting an exact ID or a unique prefix. (#532)
- Enable the web search tool for a session with the `--search` flag or the `search` config field; `web_search` remains off by default. (#533)
- Name a new interactive session at startup with `--name <title>`. (#528)
- Get feedback when denying a tool request: press **D** at a confirmation to deny with a short reason that is sent to the agent so it can adjust. (#551)
- Redirect the agent once when a tool repeats the same failure, so it tries a different approach instead of looping. (#560)
