### Features

- Sign in explicitly to compatible remote MCP servers with OAuth using `/mcp auth <name>` or `agav mcp auth <name>`. Startup reuses or refreshes cached credentials and summarizes servers needing authentication without automatically opening a browser. In-session login reconnects immediately; `/mcp logout <name>` disconnects the server and removes local credentials without restarting. Provider authorization grants are not revoked by logout. (#519)
- Queue requests submitted while Agav is busy and process them in submission order, with cancellation-safe handoffs that preserve attachments and the next draft. Inspect or cancel queued requests with `/queue` or Ctrl+Q, and retry failed dispatches with `/queue retry`. (#516)
- Use consistent searchable, paginated resource managers for agents, skills, memories, schedules and saved-session history, with inspection and the management actions supported by each resource. Explicit text commands remain available for scripts. (#458)
- Choose the launch working directory with `--cwd <dir>` or `--cwd=<dir>`, including relative paths. Invalid or inaccessible directories produce a helpful startup error. (#424)
- Copy the latest text-bearing assistant message with `/copy`, or an earlier message with `/copy N`, without copying tool-only messages. (#423)
- Search for matching file names without returning their content using `grep_search(files_only: true)`. Each matching text-file path is returned once, with bounded output and an overflow notice. (#511)
- Set a bounded execution timeout with `run_command(timeout_ms: ...)`: integer values from 1 to 120,000 milliseconds are supported, while the default remains 30 seconds. (#510)

### Fixes

- Keep `/steer` and `/plan` acknowledgements in transcript order, update the current plan in place, and deliver steering independently to running subagents with named delivery acknowledgements. (#515)
- Apply `--max-turns` consistently across interactive, print and run modes. Independent prompts receive fresh agent-loop request allowances; subagents, native agents and skills share the active allowance, while automatic continuations and JSON-schema corrections retain it. Reject invalid limits before starting work. (#339, #460, #461, #462, #463, #464)
- Count the effective prompt in `/context`, avoid double-counting its embedded skill catalog, classify MCP tools by metadata, and distinguish estimated context occupancy from cumulative session token totals. In-flight output is identified as excluded while streaming. (#517)
- Resolve context windows using provider metadata, correct DeepSeek's context-window lookup, and update model fallbacks. Interactive sessions can request a manual context window for OpenRouter models confirmed absent from its catalog rather than treating transient catalog failures as missing models. (#450)
- Include Gemini thinking tokens in output usage, and preserve signed tool-turn replay metadata with the conversation rather than in a shared provider cache, preventing overlapping requests from contaminating each other's history. (#427, #426)
- Preserve MCP tool-level error status so failed tool results are not presented to the agent as successful output. (#443)
- Scope automatic verification guidance to the requested change and report setup blockers instead of encouraging unrelated repairs. Missing test-runner executables no longer trigger source-code repair attempts; unavailable runners still do not count as passing verification. (#509, #513)
- Do not advertise or register the unavailable plan updater in pipe/headless runs, preventing accidental mutations of an interactive session's plan. (#514)
- Require the user's `AGAV_NO_SANDBOX=1` opt-out before a model can explicitly request an unsandboxed override; tool approval alone does not authorize bypass. Failed launches of a selected Seatbelt or Bubblewrap sandbox no longer silently retry unsandboxed. (#465)
- Serialize in-process edits and writes to the same canonical file path across registries and subagents, preserving undo snapshots and preventing lost independent edits. (#516)
- Preserve source line breaks and wrap-boundary spacing when copying selected text instead of treating terminal soft wraps as newlines, and exclude decorative user-message padding. (#457)
- Make expanded pasted content easier to inspect with a bounded, caret-following viewport and visual-row navigation, and show repeat-paste expansion guidance only when applicable. (#449)
- Clearly distinguish `!` shell mode, keep execution responsive and cancellable, and show captured command output literally and separately from assistant analysis, including when analysis cannot start. (#447)
- Preserve literal arguments after the `--` option separator, including in delegated agent and skill commands. (#436, #437)
- Avoid duplicating skill arguments already embedded through `$ARGUMENTS`, while preserving literal replacement characters and arguments needed after shell preprocessing. (#512)
- Treat leading-dash grep patterns as patterns rather than options, and resolve absolute `overview` paths correctly. (#440, #438)
- Parse LSP response frames by UTF-8 byte length and promptly release pending requests and timers after settlement or transport failure. (#441, #442)
- Respect Agav's post-stable beta release cycle: beta installs do not downgrade to the same-core stable release, numeric beta counters are ordered correctly, and stable installs remain on the stable channel. (#459)
- Preserve the original launch directory across automatic-update restarts so a relative `--cwd` is not applied twice. (#435)
- Restore atomic JSON trajectory exports for `run` and print modes using `--trajectory <path>`, retaining committed history through compaction and retries and available history after execution failures. (#468)
- Display complete cached release-note content in `/changelog` without the previous bullet-count and character truncation, while excluding installation instructions. (#414)

### Other changes

- Reduce default tool schemas by making GitHub, notebook and LSP tools opt-in through explicit skill or native-agent tool selections. Shell schemas advertise only installed sandbox overrides and explain the detected default. (#466, #469)
- Prune excluded directories during file searches, align grep exclusions across implementations, and return compact LSP definition and reference results. (#439, #429, #431)
- Dispatch explicit skill slash commands directly without an initial model-routing request, and return successful native agents' final answers without concatenating intermediate narration; progress reporting remains available. (#430, #428)
- Use a compact block-character startup logo on Windows while retaining the Braille logo on macOS and Linux. (#456)
- Require reviewed version-specific notes before stable release builds and publication, and avoid duplicate GitHub-generated changelog sections. (#414)
- Update the Anthropic and OpenAI SDKs, PDF.js and Node typings; add the MCP SDK for OAuth support. Refresh docs dependencies, including Next.js, React, Radix components and Lucide icons, with matching lockfiles and SDK transport test expectations. (#519, #525)
- Update reference documentation for MCP authentication, tool behavior, iteration limits, non-interactive workflows and security controls, and expand regression coverage for the changes above.
