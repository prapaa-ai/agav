# Create, Install, and Use Skills

See [Skills](/features/skills) for the skill format, scope, installation commands, and a minimal example. For live activity, retained recent tool actions, and token usage, see [Watch a running skill](/features/skills#watch-a-running-skill). Review [Permissions still apply](/features/skills#permissions-still-apply) before using a skill that edits files or runs commands, especially a manual-only skill.

For interactive management, bare `/skills` opens installed skills and `/skills marketplace` opens the marketplace. Both support search and paginated inspection with `ENTER` or `i`; use `a` to install from Marketplace, `t` to toggle in Installed, and `d` to delete eligible global skills after confirmation. `/skills list` stays textual. See [From the marketplace](/features/skills#from-the-marketplace) for all controls and restart requirements.

Continue with [Author and Evolve Skills](/guides/create-search-skill) when you need a complete improvement workflow.
