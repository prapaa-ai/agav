# Agav Documentation

Agav is a terminal-native AI coding assistant for real repositories. It can inspect code, edit files, run commands, and help verify changes from a CLI-first workflow.

New to Agav? Follow the four-page path below. You do not need to understand agents, tools, skills, or model settings before you begin.

## Get started

1. [Install Agav](/getting-started/installation)
2. [Connect a model provider](/getting-started/providers)
3. [Complete your first repository task](/getting-started/quick-start)
4. [Add instructions for your project](/getting-started/projects)

The [Getting Started overview](/getting-started) lists what you need and what you will learn at each step.

## Learn advanced workflows

After you are comfortable with the basics, use the [guides](/guides) for complete recipes involving subagents, skills, MCP, plugins, and long-running work. Use the [features](/features) section when you want to understand an individual capability.

> **Workspace boundary:** Agav treats the directory where you start it as the active workspace. Start at your repository root so it can see the whole project.
